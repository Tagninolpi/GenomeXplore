# Changelog

All notable changes to this project are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com) and the project uses
[Semantic Versioning](https://semver.org).

## [1.0.0] - 2026-11-13

### Added
- Setup page: search an NCBI taxid, explore the fields of the reference assembly reports (schema tree with completeness), save, select and remove field mappings.
- Base query page: result table (one row per assembly, mapped fields only) with paging.
- Import of your own data (JSON) as new columns.
- Data source: NCBI reference assemblies (RefSeq and GenBank).
- Docker image and `docker compose` install.
